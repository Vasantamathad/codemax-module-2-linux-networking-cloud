# Module 2 Submission Guide

## Step 1 — Push to GitHub

Create a new GitHub repository, for example:

```text
codemax-module-2-linux-networking-cloud
```

Then from this project folder:

```bash
git init
git branch -M main
git add .
git commit -m "Complete Module 2 Linux Networking Cloud Infrastructure"
git remote add origin https://github.com/<YOUR_USERNAME>/codemax-module-2-linux-networking-cloud.git
git push -u origin main
```

## Step 2 — Verify the repository

Make sure these are visible:

- README
- Linux notes
- Networking notes
- Cloud deployment guide
- Scripts
- Website
- Security checklist
- Architecture diagram
- Evidence folder

## Step 3 — Submit GitHub link

Use:

```text
https://github.com/<YOUR_USERNAME>/codemax-module-2-linux-networking-cloud
```

in the Codemax Module 2 submission.
